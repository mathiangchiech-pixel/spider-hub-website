The loader snippet

The one line you run, what it needs, and what it does.

Keyed script (most purchases)

Paste your license key on top, then the loader line. Run both.

script_key = "YOUR_LICENSE_KEY"
loadstring(game:HttpGet("https://spiderhub.xyz/files/v4/loaders/SCRIPT_FILE_ID.lua"))()

Keyless script (free / public)

No key needed — just the loader line.

loadstring(game:HttpGet("https://spiderhub.xyz/files/v4/loaders/SCRIPT_FILE_ID.lua"))()

What your executor needs

The loader runs in a Roblox/Luau executor. That executor must provide an HTTP request function (such as game:HttpGet or request), a hardware-ID provider, SHA-256 hashing (crypt.hash or syn.crypt.hash), and loadstring. Most mainstream executors have all of these. It is not a plain Lua 5.4 program and will not run in a normal Lua interpreter or a browser.

What happens on each run

  1. The loader reads your script_key and your device HWID.
  2. It asks the server for a one-time ticket (valid about two minutes).
  3. It exchanges that ticket for the protected script.
  4. It checks the script's integrity, then runs it.

Every run re-checks your key — if the seller disables the script, bans or expires your key, it stops working on the next run.

Keep your key private. Anyone who has your key and the loader can run it on their own device until the key is bound to a device.
